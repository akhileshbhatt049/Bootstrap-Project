# Bootstrap Project

A simple multi-page website developed using HTML, CSS, and Bootstrap as part of my frontend web development practice.

## About the Project

This project was created to gain practical experience with **Bootstrap**, a popular frontend framework used for developing responsive and mobile-friendly websites.

Through this project, I practiced using Bootstrap components, grid layouts, navigation elements, and styling utilities to create a structured multi-page website.

The main goal was to understand how Bootstrap simplifies frontend development and helps build responsive user interfaces.

## Technologies Used

- **HTML5** – Structuring web pages.
- **CSS3** – Custom styling and design.
- **Bootstrap** – Responsive layouts and pre-built UI components.

## Pages

- **Home Page** – Main landing page of the website.
- **About Us Page** – Information about the website.
- **Contact Page** – Contact information and communication section.

## Project Structure

```text
Bootstrap-Project/
│
├── Images/          # Website images and visual assets
│
├── About-us.html    # About Us page
├── Index.html       # Homepage
└── contact.html     # Contact page
```

## Key Learning Outcomes

Through this project, I practiced:

- Understanding Bootstrap's grid system.
- Creating responsive website layouts.
- Using Bootstrap components and utility classes.
- Designing navigation bars and page sections.
- Structuring multi-page websites using HTML.
- Combining Bootstrap with custom CSS.
